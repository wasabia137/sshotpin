📌 SshotPin 使用说明

随时可从托盘图标 → ❓ 使用说明与快捷键 重新打开。

全局快捷键

—区域截图
—把复制的图片钉到屏幕上
—屏幕放大 / 缩小
—屏幕标注
—计时器
—遮盖
不合适的快捷键可在托盘 → ⚙️ 设置中更改或清除。 清除后仍可通过快捷栏执行。

📸 区域截图

拖动选择要截取的区域
拖动蓝点调整选区大小
在选区内拖动移动选区
工具按钮✏️画笔 ↗箭头 ▭矩形 ◯椭圆 🖍荧光笔 🔲马赛克 ①编号
↩ / Ctrl+Z / 右键撤销绘制
Enter 或 📌钉到屏幕上
Ctrl+C / Ctrl+S复制 / 保存为 PNG
🙈 按钮用遮盖挡住选区
Esc取消工具;再按一次退出
截取资料、加上箭头再展示时很方便。选好工具,在区域内绘制后按 Enter。

🙈 遮盖

拖动选择要遮盖的区域;松开即创建

拖动移动遮盖

⏱️ 计时器

1·3·5·10·15分钟按钮按下即以该时长开始
点击时间直接输入 — 5:30 或 10
滚轮 / ±30秒按钮以 30 秒为单位调整
Space 或 ▶开始 / 暂停
Esc关闭
