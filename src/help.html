📌 스샷핀 사용법

스샷을 콕! 화면에 붙이는 수업 특화 캡처 도구 — 이 창은 트레이 아이콘 → ❓ 사용법·단축키에서 언제든 다시 열 수 있습니다.

전체 단축키 (어디서든 사용)

F1영역 캡처 — 드래그로 화면 일부를 찍습니다
F2정답 가리개 — 드래그한 영역을 가림판으로 덮습니다
F3클립보드에 복사된 이미지를 화면에 핀
Ctrl+1화면 확대·축소 (수업 중 잘 안 보이는 부분 크게)
Ctrl+2판서 — 화면 위에 바로 그리기
Ctrl+3수업 타이머 켜기/끄기
💡 단축키가 다른 프로그램과 겹치나요? 예를 들어 엑셀·한글에서 F1은 도움말입니다. 트레이 아이콘 우클릭 → ⚙️ 설정에서 원하는 키로 바꾸거나, 아예 비워둘 수 있습니다. 비워두더라도 퀵 실행바 버튼으로 모든 기능을 쓸 수 있습니다.

📸 영역 캡처 (F1)

드래그캡처할 영역 선택
파란 점(핸들) 드래그선택한 영역 크기 조절 — 다시 그릴 필요 없습니다
영역 안쪽 드래그선택 영역 위치 이동
도구 버튼캡처한 자리에서 바로 그리기 — ✏️펜 ↗화살표 ▭사각형 ◯원 🖍형광펜 🔲모자이크 ①번호
↩ 또는 Ctrl+Z그린 것 되돌리기
Enter 또는 📌 버튼선택 영역을 화면에 핀 (가장 많이 쓰는 기능!)
Ctrl+C클립보드에 복사
Ctrl+SPNG 파일로 저장
🙈 가리개 버튼선택 영역을 가림판으로 덮기
Esc그리기 도구 해제 → 다시 누르면 취소
💡 자료를 찍고 화살표 하나 넣어서 학생들에게 보여줄 때 가장 편합니다. 도구를 누르고 영역 안에 그린 뒤 Enter로 화면에 고정하세요.

🙈 정답 가리개 (F2)

드래그가릴 영역 선택 — 놓는 즉시 가림판 생성
클릭공개 ↔ 다시 가리기 (퀴즈 정답 공개용)
드래그가림판 이동
우클릭가리개 색 바꾸기 (남색·칠판 초록·회색·포스트잇 노랑)
휠 클릭 또는 Esc닫기
💡 문제를 띄워놓고 정답 부분만 F2로 덮어두세요. 학생들 답을 들은 뒤 클릭 한 번으로 공개!

📌 핀 (화면에 붙은 이미지)

드래그이동
휠확대 / 축소
Ctrl+휠투명하게 / 진하게
더블클릭접기 / 펼치기
휠 클릭 또는 Esc닫기
0원래 크기·투명도로
1 / 2시계 / 반시계 90° 회전

우클릭메뉴 — 테두리 표시·색상, 확대/투명도 설정, 클릭 통과 등
💡 클릭 통과: 핀을 참고자료처럼 화면에 깔아두고 아래 프로그램을 그대로 조작할 수 있습니다. 해제는 트레이 메뉴 → "클릭 통과 모두 해제".

아래 도구모음색·펜 굵기·지우기·칠판·핀·복사·저장을 전부 마우스로 조작 가능
휠확대 / 축소 (마우스를 움직이면 화면이 따라 이동)
드래그펜으로 그리기 (밑줄·강조)
Shift+드래그직선 긋기
Ctrl+드래그사각형
Ctrl+Shift+드래그화살표
Tab+드래그원 / 타원

🔲 버튼 또는 M모자이크 — 켜고 드래그하면 그 부분을 가립니다 (학생 이름·개인정보 가리기)

Esc닫기

기타

퀵 실행바화면 위에 떠 있는 작은 버튼 모음 — 단축키 없이 클릭으로 모든 기능 실행. ⠿ 손잡이로 이동, ✕로 숨기기 (트레이에서 다시 켜기)
트레이 아이콘 더블클릭영역 캡처 (F1과 동일)
트레이 우클릭전체 메뉴 — 핀 모두 숨기기/닫기, 퀵바·자동 실행 설정, 업데이트 확인, 종료
⚙️ 설정단축키 변경, 저장 폴더 지정, 바로 저장(위치 안 묻기), 퀵바·자동 실행
💡 컴퓨터 시작 시 자동 실행은 트레이 메뉴나 ⚙️ 설정에서 켜고 끌 수 있습니다. 켜두면 부팅 후 바로 쓸 수 있습니다.
