主な機能

キャプチャして、貼り付けて、その上に描く

プレゼン・授業・リモートサポート — 画面を見せながら説明するあらゆる場面で。

キャプチャして最前面にピンCtrl+F1

必要な部分だけドラッグして撮り、すべてのウィンドウの上に固定します。他のアプリで作業していても表示されたまま — 資料を見ながらの作業に最適です。撮ったその場で矢印や蛍光ペンも載せられます。

画面拡大Ctrl+1

マウスの周りをなめらかに大きく表示します。ホイールで倍率を調整し、マウスを動かすと画面が追従。小さな文字を見せるときに便利です。

画面に書き込みCtrl+2

画面の上に直接下線・丸・矢印を描きます。色や太さを変えたり、ホワイトボードに切り替えたり。描いた画面はピン・コピー・保存で残せます。

インストール方法

  1. 上のダウンロードボタンでインストーラーを入手します。
  2. ダウンロードした SshotPin-Setup.exe を右クリック → プロパティ → 下部の「許可する」にチェック → OK
    これでWindowsの警告が出なくなります。飛ばしてもインストールはできます。
  3. ファイルをダブルクリックして案内に従いインストールします。
  4. 完了すると使い方ウィンドウが開き、「PC起動時に自動実行」を尋ねます。オンにすると次回起動からすぐ使えます。

「WindowsによってPCが保護されました」が出たら詳細情報 → 実行。手順2を先にやれば表示されません。
Macは DMG を開いてアプリケーションにドラッグし、初回は右クリック → 開く。
SshotPinはウィンドウではなくタスクトレイに常駐します。アイコンを右クリックで全メニュー。

FAQ

よくある質問

SshotPinは無料ですか?

完全に無料です。支払いも登録も不要で、使用期限もありません。

普通のキャプチャツールと何が違いますか?

多くのツールは保存や貼り付けで終わりです。SshotPinはキャプチャを付箋のように最前面に固定します。他のプログラムで作業中も表示されるので、資料を見ながら作業できます。

「WindowsによってPCが保護されました」と表示されます。

コード署名証明書のないプログラムにWindowsが表示する案内です。インストーラーを右クリック → プロパティ → 「許可する」にチェックして実行すれば表示されません。既に出た場合は詳細情報 → 実行。

ウイルス対策ソフトがブロックします。

新しい未署名プログラムは予防的にブロックされることがあります(誤検知)。SshotPinはローカルでのみ動作します。例外(信頼)に登録して再インストールしてください。

どのパソコンで使えますか?

64ビット版 Windows 10・11、macOS(Apple Silicon · Intel)で動作します。Mac版はダウンロードボタンでチップを選んでください。

どんなときに使いますか?

画面を見せながら説明する場面全般です。プレゼンでは資料を固定して拡大・書き込み、授業では答えを隠してクリックで公開、リモートサポートでは矢印を載せて送り、画面共有中はモザイクで個人情報を隠します。

インストール後、アプリが見当たりません。

SshotPinはウィンドウを開かず、タスクトレイに常駐します。アイコンを右クリックで全メニュー、Ctrl+F1ですぐキャプチャ。
