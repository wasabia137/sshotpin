GET STARTED

How to install

  1. Hit the Download button above to get the installer.
  2. Right-click the downloaded SshotPin-Setup.exe → Properties → check "Unblock" at the bottom → OK
    This prevents the Windows warning. Skipping it is fine too — it still installs.
  3. Double-click the file and follow the installer.
  4. When it finishes, a how-to window opens and asks about "start at login". Choose Enable and it's ready from the next boot.

If you see "Windows protected your PC", click More info → Run anyway. Doing step 2 first prevents it.
On Mac, open the DMG, drag the app to Applications, and right-click → Open on first launch.
SshotPin lives in the system tray, not a window. Right-click the tray icon for the full menu.

FAQ

Frequently asked questions

Is SshotPin free?

Completely free. No payment, no sign-up, no time limit.

How is it different from a normal screenshot tool?

Most tools end at saving or pasting. SshotPin pins the capture on top like a sticky note — it stays visible while you work in other programs, so your reference stays in view.

I see a "Windows protected your PC" warning.

Windows shows this for programs without a paid code-signing certificate. Right-click the installer → Properties → check "Unblock", then run it. If it already appeared, click More info → Run anyway.

My antivirus blocks the installer.

New unsigned programs are sometimes flagged preventively (a false positive). SshotPin works entirely locally. Add the file to your antivirus exceptions and reinstall.

Which computers does it run on?

64-bit Windows 10·11, and macOS (Apple Silicon · Intel). For Mac, pick your chip from the download button.

When would I use it?

Anywhere you explain things on screen. Presenters pin materials and zoom or draw to point things out; teachers cover an answer and reveal it with a click; for remote help, capture and add arrows; during screen shares, mosaic private info.

The app doesn't appear after installing.

SshotPin doesn't open a window — it lives in the system tray. Right-click the icon for the full menu, or press Ctrl+F1 to capture right away.
