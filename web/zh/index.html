截取并置顶钉住Ctrl+F1

开始使用

安装方法

  1. 点击上方下载按钮获取安装包。
  2. 右键下载的 SshotPin-Setup.exe → 属性 → 勾选底部的"解除锁定" → 确定
    这样就不会出现 Windows 警告。跳过也能安装。
  3. 双击文件,按向导安装。
  4. 安装完成后会打开使用说明窗口,并询问"开机自动启动"。选择开启,下次开机即可直接使用。

如果出现"Windows 已保护你的电脑",点击更多信息 → 仍要运行。先做第 2 步就不会出现。
Mac 上打开 DMG,拖入"应用程序",首次运行时右键 → 打开。
SshotPin 不开窗口,常驻任务栏右侧托盘。右键图标可打开全部菜单。

FAQ

常见问题

SshotPin 免费吗?

完全免费。无需付费、无需注册,也没有使用期限。

和普通截图工具有什么不同?

大多数工具截完保存或粘贴就结束了。SshotPin 把截图像便签一样钉在屏幕最前面 — 切换到其他程序也一直可见,方便对照资料工作。

出现"Windows 已保护你的电脑"警告。

这是 Windows 对没有付费代码签名证书的程序的默认提示。右键安装包 → 属性 → 勾选"解除锁定"后运行即不再出现。已经出现的话,点击更多信息 → 仍要运行。

杀毒软件拦截了安装包。

新发布的未签名程序有时会被预防性拦截(误报)。SshotPin 完全在本地运行。把文件加入杀毒软件的信任列表后重新安装即可。

支持哪些电脑?

64 位 Windows 10·11,以及 macOS(Apple Silicon·Intel)。Mac 版请在下载按钮中选择芯片类型。

什么时候用?

任何对着屏幕讲解的场合。演示时钉住资料、放大并标注要点;教学时钉住题目、遮住答案再点击公开;远程协助时截图加箭头;共享屏幕时用马赛克遮住隐私。

安装后找不到程序。

SshotPin 不打开窗口,常驻任务栏右侧的系统托盘。右键图标可使用全部功能,按 Ctrl+F1 立即截图。
