윈도우 캡처 도구로 되는 것과 안 되는 것

찍어서 붙여넣는 게 목적이라면 Win+Shift+S로 충분해요. 막히는 곳은 따로 있어요.

2026-09-06 작성

윈도우 캡처 도구는 잘 만든 기능이에요. 아무것도 깔지 않아도 Win+Shift+S 한 번이면 영역을 골라 찍고, 화살표까지 그릴 수 있으니까요.
찍어서 어딘가에 붙여넣는 게 목적이라면 이걸로 충분해요. ✂️

캡처 도구로 되는 것

  • 영역·창·전체 화면·자유형 중에 골라 찍기
  • 3초·10초 지연 캡처 — 메뉴를 펼쳐놓은 상태를 찍을 때 써요
  • 펜, 형광펜, 지우개, 자로 표시하기
  • 찍은 뒤 잘라내기와 저장
  • 윈도우 11에서는 화면 녹화까지

기능이 적지 않아요. 캡처와 간단한 표시까지는 여기서 끝나요.

캡처 도구로 안 되는 것

막히는 지점은 화면을 놓고 설명해야 할 때부터예요.

찍은 것을 띄워두기편집 창을 닫으면 그림도 사라져요. 참고할 표를 옆에 두고 다른 창에서 작업할 수 없어요.
여러 장 다루기클립보드는 한 장뿐이라, 다음 걸 찍는 순간 앞의 것이 없어져요.
화면 확대돋보기는 따로 있지만 화면 전체가 움직여서 발표 중에 쓰기 어려워요.
지금 보이는 화면에 그리기펜은 찍은 그림 안에서만 돼요. 웹페이지나 엑셀을 띄운 채로는 못 그려요.
가려뒀다 공개하기정답을 덮어두고 나중에 여는 식으로는 못 써요.

둘을 같이 쓰면 돼요

스샷핀을 깔아도 Win+Shift+S는 그대로 살아 있어요. 단축키가 겹치지 않게 Ctrl+F1을 쓰거든요.
그래서 하던 대로 캡처 도구를 쓰시다가, 띄워두거나 확대하거나 그려야 할 때만 스샷핀을 꺼내면 돼요.

쓰임을 나눠 보면 이렇게 돼요.

찍어서 붙여넣기캡처 도구로 충분해요
찍어서 띄워두고 작업하기스샷핀 Ctrl+F1 → Enter
작은 글씨를 크게 보여주기스샷핀 Ctrl+1
화면에 표시하며 설명하기스샷핀 Ctrl+2
화면 녹화캡처 도구나 게임 바(Win+G)를 쓰세요. 스샷핀은 녹화를 안 해요
맥에서도 마찬가지예요. Cmd+Shift+4는 그대로 두고, 스샷핀은 Ctrl+Shift+1을 써요.

깔기 전에 알아두면 좋은 것

스샷핀은 유료 코드 서명 인증서를 붙이지 않았어요. 그래서 윈도우에서 설치할 때 "PC를 보호했습니다" 안내가 뜰 수 있어요.
내려받은 파일을 우클릭해 속성에서 "차단 해제"를 체크하고 실행하면 안 떠요. 이미 떴다면 추가 정보 → 실행을 누르시면 돼요.

맥용은 애플 공증까지 마쳤기 때문에 경고 없이 열려요. 🙂

이어서 읽기

  • 윈도우·맥 화면 캡처 단축키, 이것만 알면 돼요
    PrtSc, Alt+PrtSc, Win+Shift+S부터 맥의 Cmd+Shift+3·4·5까지 화면 캡처 단축키를 모았습니다. PrtSc가 안 눌릴 때 볼 것과, 기본 키만으로는 안 되는 네 가지도 함께 정리했습니다.
  • 스크린샷을 화면 맨 위에 붙여두는 법
    참고할 자료를 스크린샷으로 찍어 화면 맨 위에 띄워두는 방법입니다. 윈도우에 이 기능이 없는 이유와, 붙여둔 뒤 크기·투명도·클릭 통과를 다루는 법까지 담았습니다.
  • 발표와 수업에서 화면 확대하기
    윈도우 돋보기와 무엇이 다른지, 마우스 자리를 중심으로 40배까지 확대하는 법, 확대한 채로 그리고 화면만 새로 바꾸는 F5까지. ZoomIt을 쓰시던 분을 위한 비교도 담았습니다.
  • 화면 위에 바로 그리며 설명하기
    웹페이지든 엑셀이든 화면 위에 바로 그리는 판서 방법입니다. 직선·사각형·화살표·순서 번호 단축키, 칠판 모드와 레이저 포인터, 모자이크로 가리는 법까지 담았습니다.
