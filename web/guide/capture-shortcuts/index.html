윈도우·맥 화면 캡처 단축키 총정리

전체 화면, 창 하나, 원하는 영역만. 어떤 키가 어디까지 되는지 한 번에 정리했습니다.

2026-09-06 작성

윈도우

PrtSc화면 전체를 클립보드에 담습니다. 파일로 남지는 않아 문서나 메신저에 Ctrl+V로 붙여야 합니다.
Alt+PrtSc지금 보고 있는 창 하나만 담습니다. 바탕화면이나 다른 창이 섞이지 않습니다.
Win+PrtSc화면 전체를 파일로 저장합니다. 화면이 한 번 어두워지고 사진 › 스크린샷 폴더에 들어갑니다.
Win+Shift+S원하는 영역을 끌어서 고릅니다. 창 캡처, 자유형도 위쪽 막대에서 고를 수 있습니다. 클립보드로 들어가고, 오른쪽 아래 알림을 누르면 그리기 화면이 열립니다.
Win+G게임 바. 화면 녹화가 필요할 때 씁니다.

넷 중에서는 Win+Shift+S가 가장 쓸모가 많습니다. 필요한 부분만 잘라내니 뒤에 자르는 수고가 없습니다.

PrtSc가 안 눌릴 때

  • 노트북은 Fn을 같이 눌러야 하는 경우가 많습니다. 키 위에 작은 글씨로 PrtSc가 적혀 있으면 그렇습니다.
  • 텐키리스나 얇은 키보드에는 아예 없기도 합니다. 이때는 Win+Shift+S를 쓰면 됩니다.
  • PrtSc를 눌렀을 때 바로 영역 선택이 뜨게 하려면 설정 › 접근성 › 키보드에서 "화면 캡처 버튼을 사용하여 화면 캡처 열기"를 켜세요.

맥

Cmd+Shift+3화면 전체를 파일로. 기본 저장 위치는 바탕화면입니다.
Cmd+Shift+4영역을 끌어서 고릅니다. 이 상태에서 Space를 누르면 커서가 사진기로 바뀌고, 창을 클릭하면 그 창만 그림자까지 깔끔하게 찍힙니다.
Cmd+Shift+5도구막대가 뜹니다. 저장 위치 바꾸기, 타이머, 화면 녹화가 여기 있습니다.
+ Ctrl위 조합에 Ctrl을 더하면 파일 대신 클립보드로 갑니다. 예를 들어 Ctrl+Cmd+Shift+4.
맥은 찍고 나면 오른쪽 아래에 작은 미리보기가 잠깐 떠 있습니다. 그걸 누르면 바로 표시하고 자를 수 있고, 그냥 두면 저장됩니다.

기본 기능으로는 안 되는 것

단축키만으로도 찍는 데는 충분합니다. 다만 화면을 놓고 설명해야 할 때부터 막힙니다.

  • 찍은 것을 띄워두기 — 참고할 자료를 찍어놓고 다른 창에서 작업하려면 계속 창을 오갈 수밖에 없습니다.
  • 찍은 자리에서 바로 표시하기 — 화살표나 동그라미를 얹으려면 그림판 같은 다른 프로그램을 거쳐야 합니다.
  • 가리기 — 화면 공유 전에 이름이나 계좌번호를 지우려면 따로 편집해야 합니다.
  • 다시 꺼내기 — 클립보드는 한 장뿐이라, 아까 찍은 것은 사라집니다.

스샷핀 단축키

위에서 막히는 것들을 채우려고 만든 도구입니다. 기본 값은 이렇고, 설정에서 원하는 키로 바꾸거나 비워둘 수 있습니다.

윈도우맥하는 일
Ctrl+F1Ctrl+Shift+1영역 캡처. 고르는 순간 클립보드로 들어가고, Enter를 누르면 그 자리에 고정됩니다
Ctrl+F2Ctrl+Shift+2복사해둔 이미지를 화면에 고정
Ctrl+F3Ctrl+Shift+3가리개 — 덮어뒀다가 클릭하면 공개
Ctrl+1Ctrl+1화면 확대
Ctrl+2Ctrl+2화면 위에 그리기
Ctrl+3Ctrl+3타이머

영역을 고른 뒤에는 그 자리에서 Ctrl+C로 복사, Ctrl+S로 저장, Ctrl+Z로 방금 그린 것 되돌리기가 됩니다. 찍은 것은 최근 24개까지 남아 있어 나중에 다시 꺼낼 수 있습니다.
