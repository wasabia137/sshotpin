캡처해서 화면에 붙이기Ctrl+F1

필요한 부분만 드래그해서 찍고 화면 맨 위에 고정합니다. 다른 창을 열어도 위에 남아, 참고 자료를 띄워두고 작업할 수 있습니다. 찍은 자리에서 화살표·형광펜도 바로 얹습니다.

화면 확대Ctrl+1

마우스 주변을 미끄러지듯 크게 봅니다. 휠로 배율을 조절하고, 마우스를 움직이면 화면이 부드럽게 따라옵니다. 작은 글씨를 보여줄 때 그만입니다.

화면에 그리기Ctrl+2

화면 위에 바로 밑줄·동그라미·화살표를 긋습니다. 색과 굵기를 바꾸고, 빈 칠판으로 전환할 수도 있습니다. 그린 화면은 핀·복사·저장으로 남깁니다.

설치 방법

  1. 위 다운로드 버튼을 눌러 설치파일을 받습니다.
  2. 받은 SshotPin-Setup.exe를 우클릭 → 속성 → 맨 아래 "차단 해제"에 체크 → 확인
    이걸 하면 윈도우 경고창이 뜨지 않습니다. 건너뛰어도 설치는 됩니다.
  3. 파일을 두 번 클릭해서 실행하고 안내에 따라 설치합니다.
  4. 설치가 끝나면 사용법 창이 열리고, "컴퓨터 시작 시 자동 실행"을 물어봅니다. 켜기를 누르면 다음 부팅부터 바로 씁니다.

"Windows에서 PC를 보호했습니다" 창이 떴다면 추가 정보 → 실행. 위 2번을 먼저 하면 나오지 않습니다.
맥은 DMG를 열어 응용 프로그램에 끌어다 놓고, 처음 실행할 때 앱을 우클릭 → 열기.
설치하면 창이 아니라 작업표시줄 오른쪽 트레이 아이콘으로 올라옵니다. 우클릭하면 전체 메뉴가 나옵니다.

FAQ

자주 묻는 질문

스샷핀(Sshot-Pin)은 무료인가요?

무료입니다. 결제도 회원가입도 없고 사용 기간 제한도 없습니다.

보통 캡처 프로그램과 무엇이 다른가요?

보통은 찍어서 저장하거나 붙여넣으면 끝입니다. 스샷핀은 캡처한 화면을 쪽지처럼 맨 위에 고정합니다. 다른 프로그램을 쓰는 동안에도 보이니 참고할 자료를 띄워두고 작업할 수 있습니다.

"Windows에서 PC를 보호했습니다" 경고가 떠요.

코드 서명 인증서를 붙이지 않은 프로그램에 윈도우가 띄우는 안내입니다. 설치파일을 우클릭 → 속성 → "차단 해제" 체크 후 실행하면 뜨지 않습니다. 이미 떴다면 추가 정보 → 실행을 누르세요.

V3 등 백신이 설치파일을 차단해요.

새로 배포된 서명 없는 프로그램을 백신이 예방 차원에서 막는 경우가 있습니다(오탐). 스샷핀은 화면 캡처 외에 네트워크로 정보를 보내지 않습니다. V3에서는 검사 결과 창에서 해당 파일 선택 → 예외(신뢰) 등록 후 다시 설치하면 됩니다.

어떤 컴퓨터에서 쓸 수 있나요?

Windows 10·11 64비트, 그리고 맥(Apple Silicon·Intel)에서 동작합니다. 맥용은 다운로드 버튼에서 칩 종류를 고르세요.

어떤 때 쓰나요?

화면을 두고 설명하는 자리 전반에 씁니다. 발표에서는 자료를 띄워두고 확대·판서로 짚어가며 이야기하고, 수업에서는 문제를 고정해두고 정답을 가려뒀다가 공개합니다. 원격으로 도와줄 때는 화면을 캡처해 화살표를 얹어 보내고, 화면 공유 중에는 모자이크로 개인정보를 덮습니다.

설치 후 프로그램이 안 보여요.

스샷핀은 창으로 뜨지 않고 작업표시줄 오른쪽 트레이 아이콘으로 상주합니다. 아이콘을 우클릭하면 전체 메뉴가 나오고, Ctrl+F1로 바로 캡처합니다.
