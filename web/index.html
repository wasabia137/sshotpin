캡처한 화면을 쪽지처럼 붙여두고 수업하세요 · 확대 · 판서 · 타이머 · 정답 가리개

⬇ 윈도우용 다운로드

Windows 10 / 11 (64비트) · 무료 · 약 81MB · v0.2.0

🍎 맥용: Apple Silicon (M1~M4) · Intel

이런 게 됩니다

수업 중에 창을 왔다갔다 하지 않아도 됩니다.

📌

화면에 붙여두기

캡처한 문제·자료를 화면 맨 위에 고정. 다른 프로그램을 써도 계속 보입니다. 스샷핀의 핵심 기능.

🔍

화면 확대

Ctrl+1로 화면을 크게. 뒷자리 학생도 잘 보이게 마우스 따라 확대됩니다.

✏️

화면에 판서

Ctrl+2로 화면 위에 바로 밑줄·동그라미·화살표. 흰/검은 칠판 모드도 있습니다.

🙈

정답 가리개

F2로 정답을 덮어두고, 학생들 답을 들은 뒤 클릭 한 번으로 공개.

⏱️

수업 타이머

Ctrl+3로 모둠활동·시험 시간 표시. 시간을 직접 입력할 수 있습니다.

📸

빠른 캡처

F1 드래그로 영역 캡처. 복사·저장·핀을 한 번에 선택.

설치 방법

3단계면 끝납니다.

  1. 위 다운로드 버튼을 눌러 설치파일을 받습니다.
  2. 받은 SshotPin-Setup.exe를 우클릭 → 속성 → 맨 아래 "차단 해제"에 체크 → 확인
    이 한 단계를 하면 다음 단계에서 윈도우 경고창이 뜨지 않습니다. 건너뛰어도 설치는 됩니다.
  3. 파일을 두 번 클릭해서 실행하고 안내에 따라 설치합니다.
  4. 설치가 끝나면 사용법 창이 열리고, "컴퓨터 시작 시 자동 실행"을 물어봅니다. 켜기를 누르면 다음부터 바로 F1을 쓸 수 있습니다.
⚠️ "Windows에서 PC를 보호했습니다" 창이 떴다면
추가 정보 → 실행을 누르면 설치됩니다. 프로그램에 문제가 있다는 뜻이 아니라, 유료 코드 서명 인증서를 붙이지 않은 프로그램에 윈도우가 기본으로 띄우는 안내입니다. 위 2번(차단 해제)을 먼저 하면 이 창이 아예 나오지 않습니다.
💡 프로그램은 작업표시줄 오른쪽 트레이 아이콘으로 상주합니다. 아이콘을 우클릭하면 모든 기능과 ❓ 사용법·단축키를 볼 수 있습니다.

단축키 한눈에

어디서든 바로 눌러 쓰세요.

핀 위에서 휠=확대/축소, Ctrl+휠=투명도, 더블클릭=접기, 우클릭=테두리 색·회전·클릭 통과 등 전체 메뉴.

자주 묻는 질문

궁금한 점을 먼저 확인해 보세요.

스샷핀은 무료인가요?

네, 완전 무료입니다. 결제나 회원가입 없이 다운로드해서 바로 쓸 수 있고, 사용 기간 제한도 없습니다.

일반 캡처 프로그램과 무엇이 다른가요?

보통 캡처 프로그램은 찍어서 저장하거나 붙여넣으면 끝입니다. 스샷핀은 캡처한 화면을 쪽지처럼 화면 맨 위에 고정해둘 수 있습니다. 다른 프로그램을 쓰는 동안에도 계속 보이기 때문에, 수업 중 문제나 자료를 띄워놓고 진행하기 좋습니다.

"Windows에서 PC를 보호했습니다" 경고가 떠요.

유료 코드 서명 인증서를 붙이지 않은 프로그램에 윈도우가 기본으로 띄우는 안내입니다. 프로그램 문제가 아닙니다. 다운로드한 설치파일을 우클릭 → 속성 → "차단 해제" 체크 후 실행하면 경고 없이 설치됩니다. 이미 경고가 떴다면 추가 정보 → 실행을 누르세요.

어떤 컴퓨터에서 쓸 수 있나요?

Windows 10과 Windows 11의 64비트 버전에서 동작합니다. 맥용(Apple Silicon·Intel)도 다운로드 버튼 아래 링크에서 받을 수 있습니다. 맥에서 처음 실행할 때 "확인되지 않은 개발자" 안내가 나오면 앱을 우클릭 → 열기를 선택하세요.

수업에 어떻게 활용하나요?

문제를 캡처해 화면에 고정해두고 풀이를 진행하거나, 정답 부분을 가리개로 덮어두고 학생들 답을 들은 뒤 클릭으로 공개할 수 있습니다. 잘 안 보이는 부분은 화면 확대로 크게 보여주고, 화면 위에 바로 밑줄이나 동그라미를 그려 설명할 수 있습니다. 모둠 활동 시간은 타이머로 표시합니다.

설치 후 프로그램이 안 보여요.

스샷핀은 창으로 뜨지 않고 작업표시줄 오른쪽 트레이 아이콘으로 상주합니다. 아이콘을 우클릭하면 모든 기능과 사용법을 볼 수 있고, F1을 누르면 바로 캡처가 시작됩니다.
