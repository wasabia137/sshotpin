ОСНОВНЫЕ ФУНКЦИИ

Снимайте, закрепляйте и рисуйте поверх

Презентации, занятия, удалённая поддержка — везде, где вы объясняете что-то на экране.

Снять и закрепить поверхCtrl+F1

Выделите нужное и закрепите поверх всех окон. Снимок остаётся на виду, пока вы работаете в других программах — идеально для справочных материалов. Стрелки и маркер можно добавить сразу же.

Зум экранаCtrl+1

Увеличивайте вокруг мыши с плавным скольжением. Колесо меняет масштаб, вид следует за мышью. Отлично для показа мелкого текста.

Рисование на экранеCtrl+2

Подчёркивайте, обводите и показывайте стрелками прямо на экране. Меняйте цвет и толщину, переключайтесь на доску, а результат закрепите, скопируйте или сохраните.

НАЧАЛО

Установка

  1. Нажмите кнопку Скачать выше, чтобы получить установщик.
  2. Правый клик по SshotPin-Setup.exe → Свойства → отметьте внизу «Разблокировать» → ОК
    Это убирает предупреждение Windows. Можно пропустить — установка всё равно пройдёт.
  3. Дважды кликните файл и следуйте установщику.
  4. После установки откроется окно руководства с вопросом об «автозапуске». Выберите Включить — и всё готово со следующей загрузки.

Если появилось «Система Windows защитила ваш компьютер»: Подробнее → Выполнить в любом случае. Шаг 2 предотвращает это.
На Mac откройте DMG, перетащите в «Программы», при первом запуске правый клик → Открыть.
SshotPin живёт в системном трее, а не в окне. Правый клик по значку — полное меню.

FAQ

Частые вопросы

SshotPin бесплатен?

Полностью бесплатен. Без оплаты, без регистрации, без ограничений по времени.

Чем он отличается от обычного скриншотера?

Большинство инструментов заканчивают на сохранении или вставке. SshotPin закрепляет снимок поверх экрана, как стикер — он виден, пока вы работаете в других программах, и справка всегда перед глазами.

Вижу «Система Windows защитила ваш компьютер».

Windows показывает это для программ без платного сертификата подписи. Правый клик по установщику → Свойства → отметьте «Разблокировать» и запустите. Если уже показано: Подробнее → Выполнить в любом случае.

Антивирус блокирует установщик.

Новые неподписанные программы иногда блокируются превентивно (ложное срабатывание). SshotPin работает полностью локально. Добавьте файл в исключения и переустановите.

На каких компьютерах работает?

64-битные Windows 10·11 и macOS (Apple Silicon · Intel). Для Mac выберите чип в кнопке загрузки.

Когда это нужно?

Везде, где вы объясняете на экране. На презентации закрепите материал и показывайте зумом или пером; на занятии скройте ответ и откройте кликом; в поддержке — снимок со стрелками; при демонстрации экрана — мозаика на личном.

После установки программы не видно.

SshotPin не открывает окно — он в системном трее справа на панели задач. Правый клик по значку — все функции, Ctrl+F1 — снимок сразу.
