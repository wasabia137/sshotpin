설치할 때 경고가 뜨면

윈도우 — 스샷핀은 유료 코드 서명 인증서를 붙이지 않아서 "Windows의 PC 보호"라는 파란 창이 뜰 수 있어요. 내려받은 파일에 이것만 해두면 안 떠요.

  1. 내려받은 Sshot-Pin-Setup.exe를 우클릭 → 속성
  2. 아래쪽 "차단 해제"에 체크하고 확인
  3. 두 번 클릭해서 설치

이미 경고가 떴다면 추가 정보 → 실행을 누르면 돼요.

맥 — 애플 공증까지 마쳐서 경고 없이 열려요. 다만 응용 프로그램 폴더로 옮겨두시는 게 좋아요. 다른 자리에서 실행하면 맥이 앱을 임시 폴더로 옮겨 화면 기록 권한이 매번 초기화되거든요.

설치하면 이렇게 시작해요

스샷핀은 창으로 뜨지 않고 트레이 아이콘에 머물러요. 설치가 끝나면 사용법 창이 한 번 열리고, 그다음부터는 단축키로 씁니다.

윈도우 — Ctrl+F1 영역 캡처 · Ctrl+1 화면 확대 · Ctrl+2 판서
맥 — Ctrl+Shift+1 영역 캡처 · Ctrl+1 확대 · Ctrl+2 판서

영역을 고른 뒤 Enter를 누르면 그 자리에 붙어요. 나머지 기능은 가이드에 정리해 뒀어요.

If Windows shows a warning

Sshot-Pin is not signed with a paid code-signing certificate, so Windows may show a "Windows protected your PC" screen. This clears it:

  1. Right-click the downloaded Sshot-Pin-Setup.exe and choose Properties
  2. Tick Unblock at the bottom, then OK
  3. Double-click to install

If the warning already appeared, choose More info → Run anyway.

macOS — the app is signed and notarized, so it opens without a warning. Move it into the Applications folder: running it from elsewhere makes macOS relaunch it from a temporary path, which resets the screen-recording permission every time.

After installing

Sshot-Pin has no main window — it lives in the tray. The help window opens once after installation, then you use the shortcuts.

Windows — Ctrl+F1 capture · Ctrl+1 zoom · Ctrl+2 draw
macOS — Ctrl+Shift+1 capture · Ctrl+1 zoom · Ctrl+2 draw

Pick a region and press Enter to pin it where it is.
